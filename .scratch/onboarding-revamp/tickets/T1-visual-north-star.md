## Question

What is the **visual direction** for the whole entry arc (landing → auth → onboarding → plan
reveal)? This is the north-star most other tickets block on.

Produce **2–3 distinct design directions** to react to, each covering:
- Mood / art direction (color usage beyond current lavender/ink tokens, imagery, depth, texture)
- Layout system for a hybrid focused-step flow (how a step is framed on screen)
- Motion language at a high level (calm/premium vs energetic/playful)
- The role of Stry / the `PixelAgent` mascot in the new look — present, minimized, or reimagined
- How auth and onboarding read as one branded family

Use the `design-directions` skill. Build cheap, concrete visual prototypes (throwaway) so the
choice is made against real artifacts, not descriptions. Stay reconcilable with the existing
Stride token system unless a direction deliberately proposes extending it. Link prototypes here;
resolution records the **chosen** direction + rationale.
